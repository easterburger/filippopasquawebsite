# Filippo Pasqua di Bisceglie - Portfolio

Personal portfolio for Filippo Pasqua di Bisceglie, built with Next.js,
vinext, GSAP, Motion, and React.

## Run locally

```bash
npm install
npm run dev
```

## Validate

```bash
npm run build
npm run lint
npm test
```

The site is prepared for OpenAI Sites hosting through
`.openai/hosting.json`.
